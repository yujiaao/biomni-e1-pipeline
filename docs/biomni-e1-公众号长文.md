# 2539 篇生物医学预印本，画出一张当代生命科学的"方法地图"

> 我们常听到一句话："AI 要颠覆生物学了。"但生物学到底在用什么方法做研究？很少有人用数据回答过。
>
> 过去几周，我们把一套自动化流水线跑了起来：从 bioRxiv、medRxiv 抓了 **2539 篇**最新的生物医学预印本，用大模型把每一篇"拆解"成任务、工具、数据库、软件四类实体，再跨论文去重、验证、聚合。最终我们得到：**5701 条研究任务、4203 个工具、472 个数据库、193 个软件**。
>
> 当这些实体被摆在一起，一张用数据说话的"当代生物学方法地图"就浮现出来了。这篇文章不聊 Pipeline 怎么搭（那是工程问题），只聊一件事——**这些论文到底在做什么，又告诉了我们什么**。

---

## 一、我们看了什么、怎么看的

先交代数据来源和方法，免得结论显得像拍脑袋。

**语料**：2539 篇预印本，来自 bioRxiv 和 medRxiv，覆盖 23 个生物医学子类（合成生物学、药理毒理、动物行为、生理学、系统生物学、癌症、免疫、微生物……），时间跨度大致 2021–2025 年。

> 为什么看预印本而不是正式期刊？因为预印本是科研最"新鲜"的一面——论文刚做完就挂出来，没有经过期刊审稿的"延迟滤镜"，最能反映当下大家在亲手做什么。正式期刊从接受到上线往往要半年到一年，等你看到，方法可能已经不是最前沿的了。

**方法**：每篇论文经过五道工序——抓取 → 信息提取 → 跨论文去重 → 质量验证 → 聚合建库。提取环节用 DeepSeek 替代 OpenAI 做结构化抽取（任务名、输入/输出、所需工具、所需数据库、难度），语义去重用本地部署的 embedding 模型。整个过程跑了约 6 分钟，产出了上面那四个数字。

**关键定义**（后面会反复用到）：在这套体系里，一篇论文被拆成四类实体——

- **任务（task）**：这篇论文想回答的科学问题或要完成的分析，比如"差异表达基因分析""构建基因工程小鼠模型"。
- **工具（tool）**：完成任务用到的手段，分三类——**湿实验技术**（在实验台上做的，如 qPCR）、**算法/软件**（跑代码的，如 DESeq2）、**AI 模型**（如 AlphaFold2）。
- **数据库（database）**：任务依赖的公共数据资源，如 PDB、KEGG。
- **软件（software）**：具体的程序/包，如 R、Scanpy。

有了这个统一的"拆解口径"，我们才能把 2539 篇论文翻译成可统计的实体，进而看出规律。需要提前说明：大模型抽取不是 100% 准确，所以我们保留了置信度字段，并把低置信度条目挑出来供人工复核（见第十节）。但宏观规律足够稳健，因为它们建立在数千篇论文的聚合之上，个别错误不会撼动分布。

## 二、术语小词典：先把这些词说人话

文章里会反复出现一堆专业名词。为了让非生物背景的读者也能读下去，这里先用大白话把它们讲清楚。懂的读者可以跳过。

- **预印本（preprint）**：论文在正式投期刊前，先挂到公开平台让大家免费看的版本。bioRxiv 偏生物，medRxiv 偏医学。
- **转录组 / 基因组 / 蛋白质组 / 代谢组**：细胞里所有 RNA 的统称叫转录组，所有 DNA 叫基因组，所有蛋白叫蛋白质组，所有小分子代谢物叫代谢组。"组学"就是"研究某一类分子全集"的学问。
- **单细胞 RNA 测序（scRNA-seq）**：把组织打成单个细胞，逐个测每个细胞表达了哪些基因。等于给成千上万个细胞各拍一张"基因照片"，看它们分别是谁、在干什么。
- **差异表达基因分析**：比较两组样本（比如生病 vs 健康），找出哪些基因的表达量明显不同——这是几乎所有组学研究的"第一步"。
- **CRISPR-Cas9**：一对"基因剪刀"，能精准剪断 DNA 上的指定位置，用来敲除、修改或插入基因。当代生物学的"万能改刀"。
- **冷冻电镜（cryo-EM）**：把样品冻在零下近两百度，用电子显微镜看原子级结构。这几年结构生物学的"主力相机"。
- **分子对接（molecular docking）**：在计算机里把一个小分子"塞"进蛋白质的口袋，预测它能不能结合、结合在哪——虚拟筛药的核心。
- **定量蛋白质组学**：不只是"有没有这个蛋白"，而是精确测出"有多少"，还能测蛋白的磷酸化修饰等状态。
- **免疫组化（IHC）/ 免疫荧光 / Western blot**：都是用抗体"染色"来找目标蛋白的技术。IHC 在切片上显色、免疫荧光用荧光标记在显微镜下看、Western blot 在胶上按分子量分开再显色。
- **qPCR**：定量 PCR，数 DNA 或 RNA 的拷贝数，生物学的"计数器"。
- **流式细胞术**：让细胞排队逐个通过激光，同时测大小和多种荧光标记，快速分选细胞群体。
- **质谱（mass spectrometry）**：把分子打碎成离子，按质量电荷比识别"这是哪个蛋白、有多少"。
- **类器官（organoid）**：在培养皿里用干细胞养出的"迷你器官"，能模拟真实组织的结构和功能。
- **多组学（multi-omics）**：同时测基因组、转录组、蛋白组、代谢组等多个层面，拼出更完整的生命图景。
- **表型（phenotype）**：一个生物体能直接观察到的特征，比如细胞形状、小鼠毛色、药效反应。
- **嵌入（embedding）**：把文字/序列变成一串数字向量，让计算机能比较它们的"语义距离"——本文做语义去重就靠它。
- **可解释 AI / SHAP**：不只给结论，还解释"模型为什么这么判断"，在生物里常用来找关键基因或通路。
- **AlphaFold2 / ESM-2 / Enformer**：AI 模型。AlphaFold2 从氨基酸序列直接预测蛋白质三维结构；ESM-2 是"蛋白语言模型"，把序列当语言来学；Enformer 从 DNA 序列预测基因表达。
- **表征学习（representation learning）**：让模型自己从数据里学出有用的"特征"，而不是人手工设计。
- **KEGG / PDB / UniProt / TCGA / GenBank**：公共数据库。KEGG 是通路图，PDB 是蛋白结构坐标，UniProt 是蛋白序列与注释，TCGA 是癌症多组学数据，GenBank 是核苷酸序列库。
- **DESeq2 / Seurat / edgeR / Scanpy / QIIME2**：生信软件。前三个是 R 语言阵营（差异表达 / 单细胞 / 差异表达），后两个是 Python 阵营（单细胞 / 微生物组）。
- **可复现性（reproducibility）**：别人按你的方法能不能得到一样的结果。生物学里这是个长期痛点。
- **长尾分布**：少数头部项占了大部分出现次数，而海量尾部项各自只出现一两次。下文会看到，生物学方法正是典型的"长尾"。

## 三、领域分布：这 2539 篇都来自哪些方向

在谈"方法"之前，先看"这些论文本身在干什么方向"。2539 篇覆盖 23 个子类，数量并不平均：

- 合成生物学 172 篇、药理毒理 171 篇、动物行为 144 篇、生理学 140 篇、系统生物学 139 篇；
- 遗传学 120、病理学 118、发育生物 107、生物工程 101；
- 生化/生信/生物物理/癌症/细胞/生态等各约 100 篇（来自配置里的每类配额上限）。

几个观察：

1. **合成生物学与药理毒理领跑**。这很符合直觉——前者是"设计生命系统"的热土，后者直接对接药物与安全评价，都是离应用最近、产出最猛的方向。
2. **系统生物学、生理学靠前**，说明"用定量/系统视角理解整体功能"正成为主流，而不只是孤立地研究单个基因或蛋白。
3. **覆盖面广但深度不均**。23 个子类都有代表，但古生物学、流行病学等偏小众的方向样本较少——这是配额策略的结果，也提醒我们：这张地图在"热门方向"上更可信，在冷门方向上样本偏薄。

这张领域分布图，是后面所有"方法规律"的底色：我们看到的"通用七件套"，是横跨这 23 个方向仍然成立的共性；而长尾里那些只出现一次的任务，往往带着某个具体方向的专属味道。

## 四、发现一：生物医学的工具环境，是"实验主导"的

这是整张地图里最反直觉、也最重要的一点。

我们把 4203 个"工具"按性质分类，得到这样一个比例：

- **湿实验技术 59%**（2476 个）——免疫荧光、qPCR、显微镜、CRISPR、质谱、流式、ELISA……
- **算法/软件 21%**（884 个）
- **经验技巧 11%**（480 个，比如"如何制备某类切片"）
- **AI 模型 7%**（297 个）
- **纯软件 2%**（61 个）

也就是说，当代生物学论文里被反复调用的"工具"，**主体根本不是代码，而是实验台上的操作**。一个号称"能复现生物学研究"的 AI Agent，如果只会写 Python、跑流程，它连一半的活都接不住——它必须能理解并"编排"湿实验协议：哪一步加什么抗体、孵育多久、用什么对照。

这直接改写了对"生物学自动化"的想象。很多人以为 AI 进实验室是从"写代码"开始的，但数据告诉我们，**实验技术才是那个最该被标准化、被复用的底座**。

举一个具体的反差：在被提及最多的工具里，排第一的是"RNA-seq 分析"（194 次），它是一个算法；但紧跟其后的第二到第七名——免疫荧光（107）、qPCR（99）、荧光显微镜（86）、Southern blot（85）、CRISPR/Cas9（61）、质谱（43）——**全是湿实验技术**。算法只在榜首"露了个脸"，后面全是手上的活。

顺带列出贯穿所有领域的"通用七件套"——它们在 2539 篇里被提及的次数高得离谱：

| 工具 | 被提及次数 | 是什么 |
|------|-----------|--------|
| RNA-seq 分析 | 194 | 测全部转录本，找差异表达 |
| 免疫荧光 | 107 | 抗体+荧光，看蛋白在哪 |
| qPCR | 99 | 数核酸拷贝数 |
| 荧光显微镜 | 86 | 看带荧光的活细胞/组织 |
| Southern blot | 85 | 检测特定 DNA 序列 |
| CRISPR/Cas9 | 61 | 基因编辑剪刀 |
| 质谱 | 43 | 鉴定并定量蛋白 |

这七件，几乎是每篇论文的"默认装备"。

**这对"自动化"意味着什么**：如果我们要给一个生物实验室装"操作系统"，优先级最高的不是再写一个数据分析包，而是把免疫荧光、qPCR、WB 这些湿实验流程数字化、可调度化。哪天 Agent 能读懂一篇 WB 协议并自动排程，它才真正迈过了那 59% 的门槛。

## 五、发现二：方法高度碎片化，但有个小而强的"共识内核"

如果只看刚才那个 59%，容易误以为生物学有一套整齐的"标准方法集"。真实情况更复杂。

**碎片化的一面**：我们提取出的 5701 条任务里，**95.6% 只被 1 篇论文提及**；4203 个工具里，**85.6% 只被 1 篇提及**。换句话说，绝大多数论文都在用自己的一套"独门方法"——每篇都在造自己的轮子，跨论文的复用率极低。

> 这解释了为什么生物学的"可复现性"长期是难题：方法太个性化，别人想照做都难对齐。当一篇论文的实验流程里有十几个"只在本文出现"的小步骤，复现它几乎等于重新发明一遍。

**共识的一面**：但在长尾之上，存在一个小而清晰的内核——被多篇论文共同反复使用的方法。它们是领域真正"说同一种语言"的地方：

**头部任务（被多篇论文共同做的研究目标）**：
- 单细胞力学表型与转录组关联分析（208 次）——研究细胞"软硬"与其基因表达的关系，是机械生物学的新热点；
- 差异表达基因分析（104 次）——组学研究的万能第一步；
- 定量蛋白质组学分析（37 次）、构建基因工程小鼠模型（37 次）；
- 系统发育分析、免疫组化分析、体内药效评估、scRNA-seq、分子动力学模拟、注释富集分析、cryo-EM 结构解析、细胞代谢分析、病理组织学检查、分子对接、CRISPR-Cas9 基因编辑……

**头部计算栈**：被反复使用的软件清一色是 R 与 Python 双雄——
- **R 阵营**：DESeq2（差异表达，7 次）、Seurat（单细胞，7 次）、edgeR（差异表达，5 次）；
- **Python 阵营**：QIIME2（微生物组，7 次）、Scanpy（单细胞，5 次）。

**头部数据库**：参考基因组（37 次）、C. elegans 基因组（32 次）、PDB（28 次）、KEGG（23 次）、NCBI GenBank（21 次）、UniProt（13 次）、TCGA（10 次）——全是"元老级"公共基础设施。

结论很明确：**生物学的"通用语"已经形成**——一套以 RNA-seq、qPCR、显微镜、CRISPR、质谱、流式、ELISA 为骨架，以 R/Python 为计算引擎，以 PDB/KEGG/UniProt 为数据底座的方法体系。新人进实验室，先掌握这个内核，就能读懂大部分论文。

一个有意思的对比：头部任务的"集中度"远低于头部工具。最热的任务出现 208 次，但占了全部任务的很小比例；而最热的工具 RNA-seq 出现了 194 次，几乎渗透进每一个组学方向。这说明**"研究问题"高度多样，"研究手段"却在收敛**——大家问的问题千奇百怪，但用来回答问题的工具，正在趋于同一套。

**为什么长尾反而是机会**：碎片化意味着没有一家工具商、没有一个平台能"通吃"。这恰恰是新进入者的空间——把那些被反复需要做、却又散落在各篇论文里的小步骤，做成标准化的"积木"，就能在不颠覆既有的情况下，悄悄成为大家默认会用的那块拼图。

## 六、发现三：AI 已经进入生物学，但眼下还是"配角"

这是很多人最关心的问题。我们的数据给了一个冷静的答案。

在所有工具里，**AI 模型类占了 7.1%（297 个）**。绝对数量不算少，但相对那 59% 的湿实验技术，它仍是少数派。头部 AI 工具长这样：

- **AlphaFold2（22 次）**：从序列预测蛋白结构，几乎是 AI 进生物学的"招牌应用"；
- 深度学习法（16 次，如从 scRNA-seq 推断细胞周期）；
- 机器学习法（9 次，如从 3'UTR 序列预测 mRNA 稳定性）；
- **ESM-2（5 次）**：蛋白语言模型；
- **Enformer（3 次）**：从 DNA 序列预测基因表达。

几个信号值得注意：

1. **AI 最成熟的应用集中在"结构预测"和"表征学习"**——也就是把序列变成结构、把数据变成可计算的特征。这是 AI 的强项（模式建模），也是生物学最缺产能的环节。过去一个蛋白结构要晶体学家熬几年，AlphaFold2 几秒钟给一个可用的预测。
2. **AI 多作"辅助分析"而非"研究主体"**：在 297 个 AI 工具里，绝大多数出现在"用 XX 模型辅助分析实验数据"的语境，而不是"AI 独立完成了某项发现"。
3. **ESM-2、Enformer 这类"基础模型"才刚露头**：它们出现的频次还很低（各 3–5 次），但增长势头值得盯——正如 NLP 里 BERT/GPT 从零星出现到无处不在只用了两年。

**AI 还没真正碰的地方**：在我们的数据里，AI 极少出现在"实验设计""假设生成""湿实验执行"这几个环节。换句话说，AI 今天扮演的是"超级分析员"，还不是"实验员"或"科学家"。这既是局限，也是最大的未开发地带——谁能把 AI 往前推一步到"设计下一步实验"，谁就掐住了下一个十年的咽喉。

占比 7% 本身就是一个机会地图：哪里只有 7%，哪里就还有大片空白等着被填。对"AI for Science"来说，这不是沮丧的数字，而是蓝海的坐标。

> 一句话：AI 在生物学里已经"入场"，但还没"主角"。它最擅长的是结构预测和特征学习，而真正的主舞台——实验设计与执行——还基本是人和湿实验的天下。

## 七、发现四：不管研究多花哨，"验证三件套"绕不开

我们统计了每个任务"依赖哪些工具"，结果发现一个稳定到有点幽默的规律：

任务最常依赖的工具，永远是这个组合——

- **Western blot（70 次）**：蛋白"有没有、有多少"的金标准验证；
- **qPCR（52 次）**
- **显微镜（44 次）/ 荧光显微镜（35 次）**
- **RNA-seq（29 次）**
- **图像分析软件（28 次）**
- **ELISA（27 次）、CRISPR/Cas9（27 次）、质谱（24 次）、流式细胞术（24 次）**

无论论文的研究目标多前沿——单细胞力学、类器官、AI 筛药——最后都要回到 Western blot + qPCR + 显微镜 这三件套上"验明正身"。这再次印证了发现一：**实验验证是生物学的硬通货**。一个新发现如果不经过 WB/qPCR/显微镜的"三重确认"，在同行眼里就站不住脚。

另一个有意思的点：图像分析软件被高频依赖（28 次）。因为显微镜拍出来的图太多、太大，靠人眼根本看不过来，必须用算法去量化。这其实暗示了一个被严重低估的 AI 落地场景——**显微图像分析**，比"让 AI 发现新定律"更早、更实、更赚钱。事实上，在我们的数据里，AI 模型类工具里就有不少正是冲着"图像分割""细胞计数""表型量化"来的。实验产生图像，图像需要 AI——这条链路，比"端到端 AI 做实验"现实得多。

## 八、案例走查：以"差异表达基因分析"为例，看一篇论文的方法链

前面说的都是宏观规律，这里用一个被提及 104 次的头部任务，把"方法链"具象化一下，让你看到一篇真实论文大概是怎么干的。

一篇做"差异表达基因分析"的论文，典型的方法链是这样的：

1. **取样与建库（湿实验）**：取实验组和对照组样本，提取 RNA，构建测序文库——这一步要靠手法和经验，是 59% 里的大头。
2. **测序（RNA-seq，194 次）**：上机测序，得到原始 reads。
3. **比对与定量（算法）**：用软件把 reads 比对到参考基因组（参考基因组数据库，37 次），算出每个基因的表达量。
4. **差异分析（R 系算法）**：用 DESeq2 或 edgeR（各被反复使用）做统计检验，挑出显著上/下调的基因。
5. **功能注释（数据库）**：把挑出的基因拿去 KEGG（23 次）、UniProt（13 次）做通路富集，看它们集中在哪些生物学过程。
6. **验证（湿实验三件套）**：挑几个关键基因，用 qPCR（99 次）验证表达趋势，用 Western blot（70 次）验证对应蛋白，用免疫荧光/显微镜（107/86 次）看空间定位。
7. **可视化与解释（软件）**：用 R/Python 画图，必要时用可解释 AI（如 SHAP）找关键驱动因子。

你看，同一个任务，方法是"湿实验打头、算法做中段、湿实验收尾、数据库贯穿全程"。**没有任何一段能脱离其他段独立存在**。这正是为什么"只做算法"的 Agent 永远复现不了一篇完整论文——它缺了第 1 步和最重要的第 6 步。

**再举一例：类器官 + CRISPR 筛选**。这是近年极火的高通量玩法（CRISPR/Cas9 出现 61 次、类器官在长尾里也频繁现身），方法链是：先在类器官里稳定表达 CRISPR 文库（湿实验打头），用慢病毒把成千上万个 gRNA 同时转入细胞（湿实验），加药筛选后回收存活/死亡的细胞做高通量测序（NGS + 算法中段），用 MAGeCK 等软件做富集分析找出"驱动基因"（R/Python 算法），最后挑 top 候选用 Western blot、qPCR、免疫荧光做功能验证（湿实验收尾）。你看，和上一个案例同构：**湿实验开篇、算法中段、湿实验收尾、数据库/软件贯穿**。区别只是规模——从"测一个基因"变成"一次筛上万个基因"。这恰恰说明，越前沿、越高通量的研究，对"湿实验编排能力"的要求反而越高，而不是越低。

## 九、任务难度分布：绝大多数研究并不"简单"

除了"用什么工具"，我们还看了"任务有多难"。5701 条任务按难度标注的结果是：

- **hard（难）2979 条**
- **medium（中）2637 条**
- **easy（易）仅 85 条**

也就是说，**97% 的研究任务是中等难度以上，真正"简单"的不到 2%**。这从另一个角度印证了生物学的复杂性：被论文反复记录的研究目标，普遍是需要多步操作、跨技术组合的分析或实验，而不是"跑一个现成脚本"就能解决的琐事。

这对"AI 科研 Agent"是个清醒的提醒：别指望用一个通用 prompt 就复现一篇论文的方法。难任务意味着多工具串联、多轮试错、对失败的容错——这正是当前 Agent 系统最薄弱的地方。也正因为难，一旦能把"难任务"可靠地拆成可执行的步骤，价值才最大。

## 十、对"AI 科研 Agent"的一张能力栈蓝图

把上面几个发现叠在一起，一张"能复现当代生物学研究的 Agent 该有什么能力"的蓝图就清楚了。它至少分五层：

1. **湿实验协议编排层**：能理解并调度免疫荧光、qPCR、WB、流式等实验流程——这是 59% 的底座，缺了它一切免谈。
2. **计算栈层**：内置 R 系（DESeq2/Seurat/edgeR）与 Python 系（Scanpy/QIIME2）的标准分析流水线。
3. **公共数据库层**：默认连上 PDB、KEGG、UniProt、GenBank、TCGA，能查、能下载、能对齐。
4. **AI 模型层**：集成 AlphaFold2、ESM-2、Enformer 等，用于结构预测与表征学习。
5. **共识内核优先层**：先把那套"通用七件套"做成开箱即用的标准组件——这是投入产出比最高的一步。

换句话说，别一上来就想造"通用科学 AGI"。先把**被 2539 篇论文反复验证过的那套方法**，做成可靠、可复用的标准件，价值就已经巨大。这跟写软件一个道理：与其从零造一个万能框架，不如先把被用烂了的几个轮子做好。

## 十一、这些发现，对不同的人意味着什么

同一张地图，不同的人该读出不同的行动项：

- **对研究者**：你的"独门方法"大概率落在长尾里（95.6% 只被一篇提及）。这既是护城河，也是风险——如果连方法都不被复用，影响力就受限。值得问：我的核心步骤里，有没有可能做成别人也用得上的标准组件？
- **对创业者 / 工具商**：59% 的湿实验底座几乎还没有像样的"数字化操作系统"。与其在算法红海里卷，不如去啃实验流程编排、Lab 自动化、显微图像分析这些"脏活累活"——它们频次高、付费意愿强、竞争反而小。
- **对投资人**：AI for Science 的热度集中在结构预测（AlphaFold2 系），但数据告诉我们真正的高频场景是实验验证与图像分析。下一个十亿美金公司，未必在"大模型"，而在"让 Western blot 和显微镜变得可调度、可量化"这件朴素的事上。
- **对学生 / 转行的人**：先吃透"通用七件套 + R/Python + 公共数据库"这个共识内核。它不能让你立刻发顶刊，但能让你读懂这个领域 80% 的论文，是所有进阶的地基。

## 十二、方法学与局限：把话说在前面

一篇负责任的文章，得交代数据的边界：

- **最高频任务可能有"过合并"**：顶部"单细胞力学表型与转录组关联分析"出现 208 次（占 8%），偏集中，可能是去重时把多个相近表述归到了同一个名字下。我们保留了这个信号，但不把它当作精确计数。
- **长尾意味着对齐噪声**：95.6% 的任务只出现一次，说明很多任务是不同论文的"个性化表述"，跨论文语义对齐仍有误差。
- **语料偏向预印本、偏向英美平台**：bioRxiv/medRxiv 不能代表全球全部生物学，也不包括已正式发表、尤其是非英语世界的工作。
- **已有质检机制**：我们生成了 `validation_report.json` 和 `review_queue.jsonl`，把低置信度条目单独挑出供人工复核，而非混进统计。
- **频率 ≠ 重要性**：某方法被提及多，只说明它"常用"，不代表它"最重要"或"最好"。这是相关性，不是因果。

这些不影响主体结论，但提醒读者：这是一张"用 2539 篇预印本描出的地图"，不是生物学的完整 census。

## 十四、结语：一张地图，和一张待办清单

把 2539 篇论文摊开来看，当代生物学研究的样子其实很清晰：

- 它是**实验主导**的——工具环境的底座是湿实验技术，不是代码；
- 它是**高度碎片化**的——95.6% 的任务只属于一篇论文，但在这片长尾之上，立着一套被反复验证的**共识内核**（通用七件套 + R/Python + 公共数据库）；
- 它**正在被 AI 渗入**，但 AI 如今是配角，最成熟在结构预测与表征学习，真正的蓝海在实验设计与显微图像分析；
- 而无论多前沿的研究，最后都要回到 **Western blot + qPCR + 显微镜** 上验明正身。

对想做"AI + 生物学"的人来说，这张地图其实就是一张待办清单：**先把那套被 2539 篇论文验证过的方法，做成可靠、可复用的标准件。** 这比追逐"通用科学 AGI"更近、更实，也更有价值。

如果你是从业者，不妨问自己三个问题：我的工具链里，有没有把那"通用七件套"做成一键可调用的标准组件？我的 Agent，能不能读懂并编排一篇 Western blot 协议？我手上的数据，能不能接上 PDB/KEGG/UniProt？这三个问题，就是这张地图给你的起点。

数据会过时，方法会迭代，但"用数据理解科学自己在怎么运转"这件事，本身值得一直做下去。

**往前看一步（2025+ 的趋势）**：三股力量正在交汇。第一，**生物学基础模型**会从 ESM-2、Enformer 的零星露头，走向像语言模型那样"预训练一次、处处微调"的常态——这会让 AI 在表征学习之外，开始触达"设计"环节。第二，**实验室自动化**与"湿实验编排"会被重新估值，因为本文证明它就是那 59% 的底座，而它今天几乎没有像样的软件层。第三，**Agent 化**会把"读论文—提取方法—自动复现—自动验证"串成闭环，让本文这种"人工跑流水线"变成"Agent 自己跑流水线"。当这三股力量合流，我们或许会看到：下一张"方法地图"，不再由人手动统计 2539 篇得到，而由一个 Agent 实时盯着预印本流，每天更新。那张地图，会比今天这张更鲜活，也更值得持续追踪。
